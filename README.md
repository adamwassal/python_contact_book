# 📇 Contact Book

A simple and user-friendly **Contact Book** application built with **Python** and an **SQL database**.  
Manage your contacts easily through a graphical interface.

## 🛠️ Built With

- 🐍 Python  
- 🗄️ SQLite (SQL database)  
- 🖥️ Tkinter (GUI library)

---

## 💾 Installation

Before running the app, make sure you have the required dependencies installed:

```bash
sudo apt install python3-tk
```
## 🚀 How to Run
Run the main GUI file with Python:

```bash
python3 gui.py
```
This will open the graphical interface for managing your contacts.

## ✨ Features
Add, edit, and delete contacts

Persistent storage with SQLite

Simple and clean UI using Tkinter
